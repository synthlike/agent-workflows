# Starting a new project

1. Install `configure-project` and the workflows you want.
2. Invoke `configure-project` from the repository root.
3. Accept or change the recommended issue backend.
4. Choose whether domain docs, RFCs, ARPs, and meeting notes are enabled.
5. Review the proposed `AGENTS.md`, `.agents/workflows.yaml`, and `docs/agents/` changes.
6. Commit the configuration before creating project artifacts.

Directories for optional artifacts should be created only when the first artifact is written.
